# Changelog

## 1.0.0 - Initial release
- Implemented core camera controller and state model.
- Movement-dependent head-bob (phase-based).
- Landing response with severity-based displacement.
- Sprint FOV multiplier with smooth transitions.
- Subtle camera roll during lateral movement.
- First-person hand transform integration (mixin-based, mapping-sensitive).
- Configuration model with persistence and Reduce Motion support.
- Presets: Vanilla, Subtle, Immersive, Cinematic (preset values included in code comments).
- Unit tests for config and interpolation.
